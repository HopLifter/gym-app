Coaching fields – where do they go?

Step 2 adds five things to every set group: set type, rep range (upper number), effort target RPE or RIR, tempo and pause. The week editor row already has 7 columns, so these can't all sit in one row. Sample: Back Squat, Week 2 (a top set plus back-offs). The editor is shown at its real width (720 px). Part 1 is the editor; part 2 is how the grid shows it.

Part 1 – Week editor

Option A – Always two lines per set group

Good: every field is visible and nothing is hidden. Less good: doubles the height of every set group, even for coaches who never use tempo or pause; the dialog gets long with 3 or 4 set groups.

Option C – Add only what you need (chips)

Good: shortest dialog; a set group shows only what it actually uses, so the screen doesn't fill with empty boxes. Less good: one click per field to add it (three clicks for set type, tempo and pause); the chips need explaining.
