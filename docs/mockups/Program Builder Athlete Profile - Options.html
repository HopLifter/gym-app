Step 3 – athlete profile screen and reference lift

Sample athlete: Sam Lee. A profile holds: the lifts and their 1RM (and an optional training max), the plate rounding, notes, and the exercises Sam cannot do (the gym's resources). The screen is reached from the Library: clicking Edit profile in an athlete's block (the layout you approved). Everything saves automatically, like the rest of the builder. Both options are shown at their real width, one under the other. Part 3 shows where the reference lift of an exercise is set.

Part 3 – Reference lift on an exercise (same in both options)

The reference lift says which lift a % load is a percentage of (and which lift the exercise counts under in the charts later). It is one field per exercise: in the settings panel (under the exercise name, so it is visible next to the set groups) and in the Add exercise dialog. The list offers the lifts of the athlete's profile, "None", and "Other…". A % set group on an exercise with no reference lift shows a small warning in the panel.
The grid is unchanged. Pause Squat is selected; the panel on the right shows the new row.
