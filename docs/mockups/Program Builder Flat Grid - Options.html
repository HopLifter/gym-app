Builder editor – flatter, less bloated

Both options remove the box around every exercise and put the superset label (A1 / A2) on the right of the prescription, so all prescriptions line up on the left. The header is shown as proposed: program settings (weeks, workouts per week) live behind Edit, no Block field, and only the buttons that belong in the editor. Option 1 keeps today's structure (names repeated in every week). Option 2 changes the structure: exercise names appear once in a left column, so the week columns only hold prescriptions. Sample: a 4-week program, Workout 1 shown in full.

Option 1 – Same grid, boxes removed

Good: no change in how the grid reads or works; each week column is self-contained. Less good: the exercise name is still repeated in every week, which takes space, and it is harder to compare one exercise across weeks.

Option 2 – Exercise rows: names once, prescriptions across the weeks

Good: by far the most compact, since each name appears once. Reads like a spreadsheet: one exercise's progression runs left to right, so a +2.5 kg per week pattern is visible at a glance. Less good: a bigger change to the grid code and to how it looks: workouts become section headings instead of a left column. Superset partners are not drawn in one frame; they are matched by the A1 / A2 labels and sit on adjacent rows.
