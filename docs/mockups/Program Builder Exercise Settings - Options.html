Exercise settings – replacing the bottom table

All three screens show the same new grid: week columns now sit between 200 and 260 px (4 weeks fill about 1040 px and stay left-aligned) and the header text is accented. The exercise selected is Bench Press in Workout 2, which has two set groups (3 × 8 at 75% and 1 × 12 at 65%), so you see how a multi-group exercise looks. Each option stacks the settings in one flat column instead of the wide table: Load type, Rest, Progression, and Superset per set group; then a small Weeks strip (click a value to edit that week), Notes, and Add set group / Move / Delete. No boxes: sections are separated by a thin line.

Option 1 – Docked side panel (grid gets narrower)

Good: always visible beside the grid, so you change a pattern and watch the grid update at once; no covering anything. Less good: the grid loses 360 px while an exercise is selected. At a 1400 px window the 4 columns still fit at 260 px; on a smaller window they shrink toward 200 px and then scroll sideways.

Option 2 – Overlay drawer (grid keeps its full width)

Good: the grid does not resize when you select an exercise, so nothing jumps. Less good: the drawer covers the last week column or two while open, so you can't watch those change. Click anywhere outside (or the ×) to close.

Option 3 – Dialog (opened with an "Edit" link on the selected exercise)

Good: the roomiest: settings on the left and the weeks strip on the right with more space per value; consistent with the week editor you already know. Less good: it blocks the grid while open, so it is a click-in, click-out workflow instead of a live panel.
