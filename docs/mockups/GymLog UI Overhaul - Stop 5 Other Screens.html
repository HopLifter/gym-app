Stop 5: other screens

All screens use the stop 3 tokens and the same flat row: name, one grey line below it, a divider line. No boxes, no pill buttons. Data: the baseline backup (36 workouts, program "Block 1 – Knee Rehab").

Three proposals for you to accept or reject:

  • P1. Delete with Undo, not with a dialog. "Delete from Queue", "Delete from History" and "Restore to Queue" do the action at once and show the message bar with Undo for 8 s. This is one tap fewer. Dialogs stay only for actions that Undo cannot easily reverse: End Current Program, Remove Next Program, Restore from Backup, Finish Workout.
  • P2. Dialogs become bottom sheets. Menus and confirm dialogs use one component that comes up from the bottom, so your thumb reaches every button. The safe button (Cancel) is far from the edge of the screen; the red button is on top.
  • P3. The set bar keeps its own Undo. "Set 2 Started · Undo" stays in the set bar, where your eyes are. The message bar is for all other messages. Alternative: move it to the message bar too, so there is exactly one Undo place. I recommend P3 as shown, because it is tested and two Undo bars cannot show at the same time over the set bar.

No data model change in stop 5.

Decision (user, 16 Nov 2026): P1 only for Restore to Queue. Delete from Queue and Delete from History keep their confirm dialog, because after the Undo time the workout is gone for good. P2 and P3 accepted. Built in v70.
