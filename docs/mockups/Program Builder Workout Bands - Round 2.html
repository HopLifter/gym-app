Workout bands – round 2

Changes since last time: (1) the workout band is toned down so it no longer sticks out next to the Week 1, 2, 3 header; (2) the week header row is sticky: scroll inside each box below to try it; (3) Week 3 of Workout 2 is removed entirely (a deload week with only two sessions), shown in two ways in Part 2. Week 3 is also the amber "Deload" week, as before.

Part 1 – Band style (scroll inside the boxes)

B1 – plain bold title. The title is the same size as exercise names but bold; only a hairline divider and extra space set it apart. Quietest option that is still easy to scan.
B2 – header-style title. The title uses the same small uppercase style as Week 1, 2, 3, and the description is normal text. The band reads as part of the header system, but workout names are less prominent.

Part 2 – A workout removed from one week

Workout 2 has no session in Week 3. Behind the scenes none of its exercises are in that week, so the GymLog file has no workout for it. Both versions keep a way back.
Version i – message only. The cell says "No workout this week" with a Restore link. Cleanest, but you can't see what was there.
Version ii – faded preview. The exercises stay visible but faded and struck through, with a Restore link above them. Shows what you removed, but it keeps the space.
