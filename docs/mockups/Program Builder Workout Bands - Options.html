Workout title bands – saving the Workout column

Option 1 from the last mockup stays (names repeated per week, so a one-off week such as a deload can differ freely). The left "Workout" column is gone. Instead each workout gets one full-width row with its title and a one-sentence description, and the exercises sit under it in the week columns, which are now 25% wide each instead of 23%. The description is edited by clicking it (✎). A workout with no description shows a faint "Add a description" prompt. Week 3 in the sample is a one-off interim deload to show how it looks: lower loads, a missing exercise ("Not in this week") and the amber Deload tag from the week-flag idea.

Band A – tinted full-width row

Good: the clearest separation between workouts, readable at a glance. Less good: a filled row is one more "box-like" element, though it replaces the whole left column.

Band B – no fill, a divider line and an underlined title

Good: flattest look, nothing filled in. Less good: the separation relies on spacing and a line, so it is a little subtler when scrolling a long program.
