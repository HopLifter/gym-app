Program Builder UI overhaul: Library with a details panel

Two options for the left side of the Library, one below the other. In the two options, one click selects an item and the right panel shows its details. The athlete profile is in the panel, and you edit it there. There is no "Not linked to an athlete" section and no green "New program" button. Each section has one "New" button only. Test data: Strength Block A (8 weeks), Sam Lee and Maria Okafor.

Option A: one list (templates, then athletes with their programs)

The left side is one list with two sections. The programs of an athlete are below the athlete. This example shows a program selected.
