1b. Option A: a tap on a closed row

A tap opens the row so that you can read or change its values. It does not change the active exercise: the green bar and the bottom bar stay on Squats. A second tap closes the row. Only "Start This Exercise" makes it the active exercise. If the active exercise still has sets that are not done, a confirm dialog comes first: "Squats is not finished. Start Incline Bench now?"
