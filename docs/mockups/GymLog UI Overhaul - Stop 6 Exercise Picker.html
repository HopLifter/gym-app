Stop 6: exercise picker

Today, "Add Exercise" adds an empty row with a dropdown of 58 names, and a typed name goes through a second field and an "Add to Exercise List" button. The new picker is one full screen for "Add Exercise" and "Change Exercise". Data: your baseline (58 exercises, 27 different names in History).

No data model change. "Recent" and the last values come from History, by exercise name (the same lookup as the "Last 3 Sessions" panel). Old backups work as before.

Five proposals for you to accept or reject:

  • Q1. A new name always goes on the Exercise List. No more names that are in a workout but not on the list. This removes the second field, the "Add to Exercise List" button and about 60 lines of code. You can still remove a name in Settings.
  • Q2. "Add Exercise" fills in the values from the last session: sets, reps, weight, RPE and rest. Not the notes, because your notes are often instructions for that day ("Increase by 2.5kg"). If the last workout has the exercise two times (a top set and back-off sets), the first row is used.
  • Q3. "Change Exercise" changes only the name. The sets, reps and weight of the row stay, because they usually come from your program.
  • Q4. The row is made only after you pick a name. "✕" adds nothing, so there are no more empty "New Exercise" rows.
  • Q5. The search field is not active when the picker opens. The keyboard would hide the Recent list. One tap on the field starts the search.

Decision (user, 17 Nov 2026): Q1 to Q5 accepted. Built in v71 with one change: the 'Add "…"' row is first only when no name contains all the typed words; otherwise it is last, so a part of a name ("curl") is not added by mistake.
