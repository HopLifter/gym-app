Stop 8: import check and progress

Today, Import adds the program at once. You cannot see what is in the file, and names in the file that are a little different from your Exercise List (for example "Conv. Deadlifts" and "Conv. Deadlift") go in as different exercises. Then History, Recent and the picker split one exercise into two.

Today, you can see only the last 3 sessions of an exercise. There is no screen that shows all sessions or the trend.

Data model: no change

The import file format stays the same. The app stores the same data as now. The check changes only which names and which program name the app writes at import. Old backups and saved data are not touched.

Proposals (your OK first)

  • I1. Check screen before import. After you choose a file or paste text, a full screen shows the program name (you can change it), where the program goes, names to check, values to check, and the workouts. Nothing changes until you tap "Add Next Program".
  • I2. Same name, other spelling. When a file name is the same as a list name after the app ignores capitals, dots, spaces, dashes and a last "s", the app uses the list name. Example: "Conv. Deadlifts" becomes "Conv. Deadlift", "Face Pull" becomes "Face Pulls". You can change it.
  • I3. New names. Other names stay as in the file and go on the Exercise List (the stop 6 rule). The row shows a similar list name, if there is one. Tap the row to choose a different name in the picker.
  • I4. Values to check. RPE that is not 1 to 10, reps or sets that are 0 or more than 100, a weight that is not a number. The check shows them; the import can still continue.
  • I5. Undo. After the import, the message bar shows "Added: Block 2 – Strength · 12 workouts" with Undo. Undo removes the program, its workouts and the new names it put on the Exercise List.
  • P1. Progress screen for each exercise. It opens from the Exercise List (tap a name) and from "All Sessions" under "Last 3 Sessions" in a workout row. It shows every time you logged the exercise, newest first, with the notes.
  • P2. One measure: the heaviest weight of each day. It is easy to understand. Estimated 1RM is possible later, but it mixes reps and weight and is less clear with RPE.

Decision (user, 17 Nov 2026): I1 to I5, P1, P2 and option A (screen 7) accepted. RPE is a whole number from 1 to 10, in GymLog and in the Program Builder. The limit below is a reminder in the roadmap. Built in v73.

Limit to know: the progress screen finds sessions by name, as Recent does now. Your Squats list mixes high bar, paused and beltless sets, because the variant is only in the notes. The chart shows that as up-and-down lines. A separate name for each variant (for example "Squats – High Bar Paused") gives a clean line. I do not propose a data change for this.
