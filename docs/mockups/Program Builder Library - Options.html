Program Builder – Library screen: layout options

Realistic sample data in every option (3 athletes, 4 programs, 3 templates, 1.2 MB of browser storage). Click the tabs in Option A. All options show the same must-haves from the spec: list of items with last edited date (dd/mm/yyyy), Open / Duplicate / Rename / Delete / Export, Generate, Export everything, Import everything, "Last exported" reminder, and the storage meter.

Option A – Full-page library with three tabs (as written in the spec)

Good: Simple, familiar, every list has the whole page. Easy to build.
Less good: Hides the editor while you browse. Programs for one athlete are not grouped. A program's athlete is only a small tag.
