Program Builder UI overhaul: settings panel options

Two options for the exercise settings panel, stacked at full width, each shown inside the proposed flatter editor (new header, add-exercise search box, quieter grid). Both remove the week editor dialog, the progression dialog and the "Apply changes to" switch: every setting lives in one place. Same test data in both: Strength Block A (8 weeks) for Sam Lee, Back Squat selected.

Option A: week table

Each set group is one small table: a row per week with sets × reps, the load and the calculated kg. Week 1 and the progression fill the other weeks; type in any other week to override it (green edge, ↺ puts it back).

Option B: compact week strip

Each set group is three lines: the prescription, the progression, and the eight weekly loads in a 4 × 2 block with kg underneath. Sets and reps apply to all weeks; a week that needs different sets or reps is changed by clicking its week label.
